Web Development Quick-Reference Guide

A handy guide for essential HTML tags and CSS properties.

Core HTML Tags

Below are 10 essential HTML tags used to structure content on a webpage.

1. <h1> to <h6> (Headings)

Used to define headings on a page, where h1 is the most important and h6 is the least important.

<h1>Main Page Title</h1>
<h2>Section Subheading</h2>

2. <p> (Paragraph)

Groups blocks of text into standard sentences and paragraphs with automatic spacing above and below.

<p>This is a sentence of text on my website.</p>

3. <ul> (Unordered List)

Creates a bulleted list of items that do not require a specific numerical order.

<ul>
    <li>First bullet item</li>
    <li>Second bullet item</li>
</ul>

4. <ol> (Ordered List)

Creates a numbered list of items, which is perfect for step-by-step methods or instructions.

<ol>
    <li>Step One</li>
    <li>Step Two</li>
</ol>

5. <li> (List Item)

Used inside either a <ul> or an <ol> tag to wrap around each individual item in the list.

<li>Just a single item inside a list</li>

6. <a> (Anchor / Link)

Creates a hyperlink to connect users to another webpage using the "href" attribute.

<a href="https://google.com">Visit Google</a>

7. <div> (Division)

A generic container used to group elements together so they can be styled easily with CSS.

<div class="box-layout">
    <p>Text inside a container.</p>
</div>

8. <span> (Inline Container)

An inline container used to mark up or style a specific word or phrase inside a larger sentence.

<p>This word is <span class="red-text">important</span>.</p>

9. <pre> (Preformatted Text)

Displays text exactly as written in the HTML file, preserving spaces, line breaks, and formatting codes.

<pre>
Line one
    Line two (indented)
</pre>

10. <code> (Computer Code)

Styles text inside a monospace font to indicate a short snippet of computer programming code.

<p>Use the <code>var</code> keyword.</p>

Core CSS Properties

Below are 8 fundamental CSS styling rules used to control layouts, colors, and fonts.

1. background-color

Sets the background color behind the text or element container.

body {
    background-color: #f4f6f9;
}

2. font-family

Defines which font style the browser should use to display the text content.

h1 {
    font-family: Arial, sans-serif;
}

3. color

Changes the specific foreground color of text elements.

p {
    color: #333333;
}

4. margin

Creates blank space *outside* of the element's border to push neighboring items away.

.box {
    margin: 20px;
}

5. padding

Generates blank space *inside* of an element, acting as a cushion between content and its border.

.card {
    padding: 15px;
}

6. border-radius

Rounds the sharp square corners of an element's container box background.

img {
    border-radius: 8px;
}

7. text-align

Sets the alignment of text inside its block container (left, right, center, or justify).

h2 {
    text-align: center;
}

8. display

Determines how an element behaves in the document layout grid (e.g., block, inline, or flex).

.row {
    display: flex;
}
